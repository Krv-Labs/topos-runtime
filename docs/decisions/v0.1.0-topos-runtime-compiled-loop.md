# Compiled-binary optimizer (v0.1.0)

Status: **accepted**. This is what ships. The earlier fabricated
evaluate/inspect/identify/recompile loop is not this design and is not
coming back.

## Decision

The compiled loop searches **clang driver flags + instrumented PGO**. It
compiles real C/C++ (single-file fast path, or `[compiled]` in
`.topos.toml`), times interleaved A/B runs, and promotes a winner only
when SPEED and SIZE both pass.

Ω_bitcode is a **parallel** four-generator lattice (SPEED, SIZE, ENERGY,
LOCALITY). It is not the source lattice and is **not** registered in
`GATE_SPECS`. LOCALITY is rendered as MEMORY FOOTPRINT (peak RSS + page
faults). ENERGY is permanently `Unmeasured` until a real counter exists.
An unmeasured generator cannot be Satisfied; all-unmeasured is SLOP and
cannot yield PLATINUM. Medal tiers use `EvaluationValue::medal_tier()`
via `from_bits`.

CLI: `topos compiled plan | approve | apply | rollback`.
MCP: `topos_compiled_plan`, `topos_compiled_apply`,
`topos_compiled_rollback`. **`approve` is CLI-only** — it is the human
gate; exposing it as a tool is the bypass the gate exists to prevent.
`plan` builds and runs nothing. `apply` refuses an unapproved plan and
prints `NO CANDIDATE MET THRESHOLDS` rather than promoting a loser.
Rollback copies the stored baseline, `sync_all`s, `rename`s, then reads
the destination back before `verified: true`.

Default variants: O2, O3, Os, lto, pgo-O3. Speedup is reported from
**medians**. The significance test is a Fisher–Pitman permutation on the
**sum** of paired wall-clock diffs (not `|median|`, which is powerless
at even `n`). Drift uses lag-1 consecutive baseline diffs.

Artifacts live under `<project>/.topos/compiled/` (gitignored). A
malformed `[compiled]` block is an error, not silent `None`.

`topos benchmark` / `topos_benchmark` remain a separate owner-owned
baseline harness. They are not this loop.

## Non-goals

These are not missing features. Do not restore them as stubs.

### `opt` pass-sequence search is the wrong axis

Hand-built `opt` pipelines over `clang -emit-llvm` bitcode skip the
driver's target and TTI setup and routinely lose to plain `-O2`.
Feeding pass names such as `loop-vectorize` to clang as argv tokens
parses them as **input filenames**, which is how the fabricated loop
produced unbuildable plans. Searching LLVM pass order is compiler
research, not a closed-loop optimizer for agent-written C.

### No MLIR, BOLT, or AutoFDO

Dialect lowering and post-link layout are not clang driver flags.

### No energy counters

No Linux RAPL via `perf`, no root `powermetrics` on macOS. ENERGY stays
Unmeasured with a pinned reason string. Do not invent a fifth generator
bit to hide the hole.

## Consequences

- Human identity is required (`--by`); there is no `--yes`.
- Path containment applies to the artifact store and the rollback dest.
- IR stats, when present, are report context and never a gate.
